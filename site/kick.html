Kick throws its chat away — so the video has to speak

Kick keeps no chat replay once a stream ends. On Twitch, chat is a useful hint about which moments landed. On Kick there is nothing to read, so a clipper that leans on audience reaction has nothing to lean on.

That is fine here, because audience data was only ever a small capped bonus. Everything that does the real work is measured from the video itself:

What was said

A local language model reads the transcript for hooks, revelations, strong opinions and quotable lines.

What it sounded like

Loudness spikes against a rolling median, laughter-shaped bursts, and the silence-then-explosion shape that marks a payoff.

What it looked like

Scene cuts, motion, and sudden changes in how much of the frame a face fills — a lean into the camera is someone reacting.

Each signal is normalised within your own video, so a calm chat stream and a shouting one both produce meaningful peaks. Nothing is scored against some average of other people's content.

Good to know

  • Finished VODs only — live streams are deliberately not supported.
  • Kick VODs download as H.264, which decodes fast in hardware. Long Kick streams process at roughly the same speed as Twitch ones.
  • No Kick account needed. No login, no API key, no rate limit to worry about.
