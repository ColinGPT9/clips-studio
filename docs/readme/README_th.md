### กดดาวและแชร์ Clips Kitty ⭐

**ฝากกดดาวให้ repo นี้และช่วยแชร์ต่อด้วย** ไม่มีค่าใช้จ่ายอะไรเลย
และโปรเจกต์นี้ไม่มีงบการตลาด การบอกต่อจึงเป็นทางเดียวที่ยูทูบเบอร์หรือสตรีมเมอร์รายเล็กคนต่อไป
จะรู้ว่ามีตัวเลือกฟรีอยู่

**ผมทำโปรแกรมนี้ขึ้นมาเพื่อยูทูบเบอร์และสตรีมเมอร์รายเล็ก** ที่ไม่มีงบจ่ายค่าบริการอื่น ๆ
หรือจ้างคนตัดต่อ นี่คือทางเลือกแทน Opus Clip, Vizard และ Klap แบบฟรี
ที่รัน **Google Gemma** บนพีซีของคุณเอง: ไม่มีค่าเซิร์ฟเวอร์ ไม่มีค่าบริการต่อคลิป
ไม่มีค่าใช้งาน AI

**เปลี่ยนสตรีมและวิดีโอยาว ๆ ให้เป็น Shorts, Reels และ TikTok ที่พร้อมโพสต์
ได้ทั้งหมดบนเครื่องของคุณเอง** แค่วางลิงก์ YouTube, Twitch หรือ Kick โปรแกรมจะหา
ช่วงที่ดีที่สุด ครอปเป็น 9:16 โดยให้คนพูดอยู่กลางเฟรม ฝังซับไตเติลที่ตรงกับคำพูดทีละคำ

ค่าเริ่มต้นไม่ใช้ AI บนคลาวด์ ไม่มีค่าสมาชิก ไม่มีค่าบริการต่อคลิป ฟุตเทจของคุณไม่ออกจาก
คอมพิวเตอร์เลย เว้นแต่คุณจะสั่งให้โพสต์คลิปไปยังบัญชีของคุณเอง

## ทำอะไรได้บ้าง

- **หาช่วงที่ดีที่สุด**: ให้คะแนนรวมกันทั้งสิ่งที่พูด ความตื่นเต้นของเสียง สิ่งที่เกิดขึ้น
  บนจอ และความแรงของช่วงเปิดคลิป ทุกคลิปที่ผ่าน
  เกณฑ์คุณภาพจะถูกเก็บไว้
- **คุยเล่น เกม และกีฬา**: ออกแบบมาสำหรับสาย IRL, Just Chatting และพอดแคสต์ โหมด
  **Gaming / Reaction** (เกม / รีแอ็กชัน) แบ่งเว็บแคมกับเกมไว้คนละครึ่ง และโหมด
  **Sports** (กีฬา) ตัดคลิปประตู การเซฟ และโอกาสสำคัญจากการแข่งขัน
- **คนพูดอยู่ในเฟรมเสมอ**: ระบบติดตามใบหน้าจะตามคนที่กำลังพูดจริง ๆ
- **ซับไตเติลแก้ไขได้**: ตรงกับคำพูดทีละคำ ปรับสไตล์ได้ตามใจ แก้ได้ทีละบรรทัด
- **ชื่อคลิป คำอธิบาย และแฮชแท็ก** เขียนให้อัตโนมัติ และแก้ไขได้ทั้งหมด
- **โพสต์อัตโนมัติ (ไม่บังคับ)**: เฝ้าดูช่อง ตัดคลิปจากวิดีโอใหม่แต่ละตัว แล้วโพสต์
  ไปยัง YouTube, TikTok และ Instagram ให้เอง บนบัญชีของคุณเอง
- **19 ภาษา**: ตัวแอปแปลไว้ 19 ภาษา และคลิปก็แปล
  ใส่ซับไตเติล และพากย์เป็นภาษาเหล่านั้นได้

## สเปกที่ต้องการ

|         | ขั้นต่ำ                                         | แนะนำ                    |
| ------- | --------------------------------------------- | ------------------------ |
| **GPU** | NVIDIA RTX 2060 (6 GB)                        | RTX 3060 12 GB ขึ้นไป     |
| **CPU** | Intel Core i3-9100 / AMD Ryzen 3 3200G (2019) | 6 คอร์ขึ้นไป               |
| **RAM** | 16 GB                                         | 16 GB ขึ้นไป              |
| **OS**  | Windows 10 หรือ 11                            |                          |

การ์ดจอไม่บังคับ: ถ้าไม่มี ทุกอย่างจะทำงานบนซีพียู ช้ากว่า
แต่ครบทุกฟีเจอร์

## ติดตั้ง

- **[Microsoft Store](https://apps.microsoft.com/detail/9NB6XT7DSQZZ)**: คลิกเดียว
  และอัปเดตตัวเองอัตโนมัติ
- **หรือใช้ตัวติดตั้ง**: **Web Setup** เวอร์ชันล่าสุดจาก
  [Releases](https://github.com/ColinGPT9/clips-studio/releases)
- **หรือ winget**: `winget install ColinGPT9.ClipsKitty`

ตัวช่วยติดตั้งจะดาวน์โหลดโมเดล AI ที่เหมาะกับการ์ดจอของคุณ หลังจากนั้นก็
ใช้งานแบบออฟไลน์ได้
